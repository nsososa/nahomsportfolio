    Home Depot Simulated Supplier Insights Dashboard

    Skills: Tableau Python Excel GitHub

    Description

    This project explores supplier performance using a simulated multi-year dataset built in Python. The analysis evaluates revenue, conversion rates, content quality, and product-level behavior, surfacing insights to guide merchandising strategy, supplier management, and digital content optimization.

    Goal: Identify performance drivers across suppliers and SKUs while quantifying opportunities for improved conversion, content quality, and customer engagement.

    This dashboard was built using a simulated dataset generated in Python. The dataset is designed to reflect realistic COVID impacts, supplier behavior, and conversion patterns. The code used to generate the dataset can be found below.

    View Python Code

    Guiding Questions

    • Which suppliers contribute the most revenue?
    • How does content quality impact conversion?
    • Where are the biggest risks—missing images, low conversion, asset quality issues?
    • What actions can merchandising teams take to improve performance?

    Business Questions

    • Which suppliers deliver the highest revenue, and how efficient are they (revenue per view)?
    • How do product page views translate through the funnel into orders?
    • How large is the missing-image problem, and which brands are most affected?
    • How does content score correlate to conversion?
    • At the SKU level, which items carry the highest risk or greatest opportunity?

    Data Generation, Simulation Design, & Preparation

    The dataset was designed to mimic:

    • COVID-era demand swings
    • Supplier-level behavior differences
    • Category-level seasonality
    • Conversion patterns across millions of views
    • Content quality variance (image completeness, asset quality, bullet quality)

    Metrics collected include:

    • Revenue, orders, conversion rate
    • Page views & funnel step counts
    • Content score & asset quality score
    • Missing image flags
    • SKU metadata (supplier, category, product type)

    1. Imports, Random Seed, and Core Dimensions

    We start by importing libraries, fixing a random seed for reproducibility, and defining the size and core dimensions of the dataset.

    Expand/Collapse Code 
    import pandas as pd
import numpy as np

np.random.seed(42)

n = 200_000
dates = pd.date_range("2020-01-01", "2025-11-01", freq="D")

suppliers = ["3M", "Milwaukee", "Ryobi", "LG", "Samsung", "Behr", "Husky", "DeWalt", "Delta Faucet"]
categories = ["Power Tools", "Appliances", "Paint", "Plumbing", "Smart Home", "Outdoor", "Flooring"]
merchants = ["Tools Online", "Appliances Online", "Decor Online", "Building Materials Online"]

    2. Seasonality, Supplier Strength, and COVID Effects

    Next, we define category-level seasonality, supplier multipliers, and a COVID-era demand shock function. These pieces introduce realistic volume variation over time and across brands.

    Expand/Collapse Code 
    # simulated seasonal patterns by month
# Multipliers try to reflect real retail + home improvement patterns
category_month_seasonality = {
    "Paint":      {1:0.6,2:0.7,3:0.9,4:1.2,5:1.35,6:1.45,7:1.4,8:1.3,9:1.1,10:1.0,11:0.85,12:0.7},
    "Power Tools":{1:1.2,2:1.0,3:1.0,4:1.1,5:1.2,6:1.3,7:1.3,8:1.2,9:1.1,10:1.1,11:1.4,12:1.6},
    "Appliances": {1:1.0,2:1.0,3:1.1,4:1.2,5:1.25,6:1.3,7:1.2,8:1.1,9:1.0,10:1.1,11:1.3,12:1.5},
    "Plumbing":   {1:0.9,2:0.9,3:1.0,4:1.05,5:1.1,6:1.1,7:1.1,8:1.0,9:1.0,10:1.05,11:1.1,12:1.1},
    "Smart Home": {1:1.1,2:1.0,3:1.0,4:1.1,5:1.15,6:1.2,7:1.2,8:1.15,9:1.1,10:1.1,11:1.3,12:1.4},
    "Outdoor":    {1:0.4,2:0.5,3:0.8,4:1.2,5:1.5,6:1.7,7:1.6,8:1.3,9:1.1,10:0.9,11:0.6,12:0.4},
    "Flooring":   {1:1.0,2:1.0,3:1.05,4:1.1,5:1.1,6:1.15,7:1.1,8:1.1,9:1.0,10:1.0,11:1.15,12:1.2},
}

# helps provide more variance in the data across suppliers
supplier_multiplier = {
    "Samsung": 3.2, "LG": 3.0,
    "Milwaukee": 2.8, "DeWalt": 2.5, "Ryobi": 2.3,
    "Behr": 1.8, "Husky": 1.3, "Delta Faucet": 1.2,
    "3M": 1.0
}

# simulating COVID shock periods (Mar 2020-Dec 2021)
def covid_multiplier(date):
    if pd.Timestamp("2020-03-01") <= date <= pd.Timestamp("2021-12-31"):
        return 1.8
    return 1.0

    3. Sampling Base Fields and Computing Seasonality Factors

    Here we randomly assign a date, supplier, and category to each row, then derive the corresponding seasonality and COVID multipliers.

    Expand/Collapse Code 
    date_col = np.random.choice(dates, n)
supplier_col = np.random.choice(suppliers, n)
category_col = np.random.choice(categories, n)

seasonal_mult = np.array([
    category_month_seasonality[c][pd.Timestamp(d).month]
    for c, d in zip(category_col, date_col)
])

covid_mult = np.array([covid_multiplier(pd.Timestamp(d)) for d in date_col])

    4. Content Quality Segmentation and Scores

    We segment SKUs into poor, average, and great content groups. Each group gets different distributions for content score, asset quality, bullet quality, and missing images—reflecting how better content usually comes with fewer issues.

    Expand/Collapse Code 
    # devising more variance in content scores depending on "missing images", "asset quality", and "bullet quality" - description quality
u = np.random.rand(n)
segment = np.where(u < 0.25, "poor",
        np.where(u < 0.75, "avg", "great"))

content_score = np.empty(n)
asset_quality_score = np.empty(n)
bullet_quality_score = np.empty(n)
missing_images = np.zeros(n, dtype=int)

# poor content: lower scores, many missing images
mask_poor = (segment == "poor")
content_score[mask_poor] = np.random.normal(52, 6, mask_poor.sum())
asset_quality_score[mask_poor] = np.random.normal(50, 12, mask_poor.sum())
bullet_quality_score[mask_poor] = np.random.normal(55, 8, mask_poor.sum())
missing_images[mask_poor] = np.random.binomial(1, 0.45, mask_poor.sum())

# average content
mask_avg = (segment == "avg")
content_score[mask_avg] = np.random.normal(72, 7, mask_avg.sum())
asset_quality_score[mask_avg] = np.random.normal(70, 10, mask_avg.sum())
bullet_quality_score[mask_avg] = np.random.normal(73, 7, mask_avg.sum())
missing_images[mask_avg] = np.random.binomial(1, 0.15, mask_avg.sum())

# great content
mask_great = (segment == "great")
content_score[mask_great] = np.random.normal(90, 4, mask_great.sum())
asset_quality_score[mask_great] = np.random.normal(88, 6, mask_great.sum())
bullet_quality_score[mask_great] = np.random.normal(89, 5, mask_great.sum())
missing_images[mask_great] = np.random.binomial(1, 0.05, mask_great.sum())

content_score = np.clip(content_score, 30, 100).round(1)
asset_quality_score = np.clip(asset_quality_score, 20, 100).round(1)
bullet_quality_score = np.clip(bullet_quality_score, 30, 100).round(1)

    5. Base Traffic and Conversion Rates by Category & Supplier

    We define base page-view intensity and base conversion rates per category, then apply supplier-level adjustments so stronger brands convert better.

    Expand/Collapse Code 
    # Different base traffic by category
base_pv_lambda = {
    "Appliances": 35,
    "Smart Home": 45,
    "Power Tools": 70,
    "Paint": 50,
    "Outdoor": 65,
    "Plumbing": 25,
    "Flooring": 30
}

# Base conversion rates by category
base_conv_rate = {
    "Appliances": 0.020,
    "Smart Home": 0.035,
    "Power Tools": 0.045,
    "Paint": 0.030,
    "Outdoor": 0.040,
    "Plumbing": 0.025,
    "Flooring": 0.028
}

# Supplier-level conversion adjustment (better brands convert better)
supplier_conv_adj = {
    "Samsung": 1.25, "LG": 1.20,
    "Milwaukee": 1.20, "DeWalt": 1.15, "Ryobi": 1.10,
    "Behr": 1.05, "Husky": 0.95, "Delta Faucet": 1.00,
    "3M": 0.90
}

    6. Simulating Page Views

    Page views are drawn from a Poisson distribution, where the rate (lambda) is influenced by category, seasonality, COVID effects, supplier strength, and additional lognormal noise to create spikes and a long tail.

    Expand/Collapse Code 
    # page views
lambda_base = np.array([
    base_pv_lambda[cat] *
    seasonal_mult[i] *
    covid_mult[i] *
    supplier_multiplier[supplier_col[i]]
    for i, cat in enumerate(category_col)
])

# add extra randomness per row (lognormal so some SKUs spike)
lambda_noise = np.random.lognormal(mean=0.0, sigma=0.4, size=n)
lambda_final = lambda_base * lambda_noise

page_views = np.random.poisson(lambda_final).astype(int)
page_views[page_views < 0] = 0  # safety

    7. Simulating Conversion, Orders, and Add-to-Cart Events

    Conversion rates start from category + supplier baselines and are modified by content quality and lognormal noise. From there, we simulate orders and add-to-cart events.

    Expand/Collapse Code 
    # conversion rates vary depending on content 
conv_base = np.array([
    base_conv_rate[cat] * supplier_conv_adj[supplier_col[i]]
    for i, cat in enumerate(category_col)
])

# content impact: ~±40–50% swing based on content_score
content_factor = 1 + 0.8 * ((content_score - 70) / 30.0)
# random noise factor per row
conv_noise = np.random.lognormal(mean=0.0, sigma=0.35, size=n)

conv_rate = conv_base * content_factor * conv_noise

conv_rate = np.clip(conv_rate, 0.001, 0.25)

# binomial conversion rates
orders = np.random.binomial(np.maximum(page_views, 0), conv_rate)

atc_prob = np.clip(conv_rate * np.random.uniform(2.0, 4.0, size=n), 0.01, 0.90)
raw_atc = np.random.binomial(np.maximum(page_views - orders, 0), atc_prob)
atc_events = orders + raw_atc

    8. Revenue Simulation Using Category-Specific AOV Ranges

    We then estimate revenue by multiplying order counts by a randomly sampled average order value range specific to each category.

    Expand/Collapse Code 
    # revenue with variance per category
category_aov = {
    "Appliances": (400, 1500),
    "Smart Home": (100, 400),
    "Power Tools": (80, 300),
    "Paint": (20, 70),
    "Plumbing": (30, 120),
    "Outdoor": (50, 250),
    "Flooring": (40, 200)
}

revenue = np.array([
    orders[i] * np.random.uniform(*category_aov[category_col[i]])
    for i in range(n)
]).round(2)

    9. Assembling the Final DataFrame

    Finally, we assemble all metrics and metadata into a single DataFrame with SKU-level detail and several operational fields (e.g., on-time uploads and content changes).

    Expand/Collapse Code

    "supplier": supplier_col,
    "brand": supplier_col,
    "category": category_col,
    "sku_id": np.random.randint(100000, 999999, n),
    "sku_name": np.random.choice([
        "Cordless Drill Kit","Smart Washer","Matte Interior Paint","Kitchen Faucet",
        "Smart Doorbell","Electric Lawnmower","Laminate Flooring",
        "Impact Driver","Mini Fridge","Exterior Paint","Shower Head"
    ], n),
    "merchant_team": np.random.choice(merchants, n),

    "page_views": page_views,
    "atc_events": atc_events,
    "orders": orders,
    "revenue": revenue,

    "content_score": content_score,
    "asset_quality_score": asset_quality_score,
    "missing_images": missing_images,
    "bullet_quality_score": bullet_quality_score,

    "on_time_upload": np.random.binomial(1, 0.85, n),
    "content_changes_made": np.random.randint(0, 20, n),
    "brand_review_meetings": np.random.randint(0, 6, n),
})

    Exploratory & Comparative Analysis

    A. Executive Summary View

    Provides high-level KPIs and trends:

    • $265.8M revenue, 3.83% average conversion rate
    • Revenue per view, content score, missing image count
    • Multi-year revenue trend showing seasonal waves
    • Supplier leaderboard comparing revenue, revenue per view, and conversion
    • Category-by-supplier performance heatmap

    This view highlights macro patterns and top suppliers (Samsung, LG, Milwaukee).

    B. Supplier Deep Dive View

    Focuses on supplier efficiency and content health:

    • Revenue bar chart across top suppliers
    • Complete funnel visualization from page views → add-to-cart → orders
    • Image health donut chart (80% complete vs. ~20% missing)
    • Content score vs. conversion scatterplot showing strong positive trend
    • Ability to filter by supplier, category, or team to identify risk areas

    This view provided actionable clarity on which suppliers are limited by poor content and which are conversion efficient.

    C. SKU-Level Detail View

    Highlights SKU-level variability and risk scoring:

    • Table with page views, add-to-cart, orders, revenue, content score
    • Flags for Critical Risk, Low Conversion, Missing Images, OK
    • Lifecycle trend showing long-term page view and order patterns
    • SKU-level content score vs. conversion scatterplot to spot high-opportunity items

    This brought attention to specific items needing content updates, new images, or repositioning.

    Key findings:

    • Supplier concentration: Top three suppliers drove ~50% of total revenue in the simulated dataset.
    • Content quality impacts conversion: SKUs above content score 80 showed conversion rates 1.5–2× higher.
    • Missing images are costly: Nearly 20% of SKUs lacked images, correlating to significantly lower conversion.
    • Funnel inefficiency: Only 4–5% of page views reached add-to-cart, indicating opportunity in improving page content and clarity.
    • SKU-level risk identification: Several high-traffic SKUs were flagged as Critical Risk due to poor content or asset quality.

    Business Impact (Simulated)

    • Targeted content improvements: Identified SKUs whose content updates could drive a 10–20% lift in conversion.
    • Supplier accountability: Clear visibility into supplier content health supported more productive vendor conversations.
    • Revenue optimization: Prioritizing missing image fixes for high-traffic SKUs could reclaim an estimated $8–12M in potential revenue.
    • Efficiency gains: Automated data refresh and well-defined metrics reduced manual reporting time by 60%.
    • Funnel clarity: Highlighted drop-off points that guided UX and content improvements.
